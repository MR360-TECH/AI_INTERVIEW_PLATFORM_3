Module 02

Assessment Token Quota & Unlock System

To prevent candidate quota spamming while maintaining fair access, the platform incorporates a robust token-governed attempt limit engine.

Phase 1
Default Quota

New candidates are allocated default attempt tokens (default: 2 sessions) configurable in Admin Settings.

Phase 2
Quota Depletion

Each completed formal assessment consumes 1 token. When remaining tokens reach 0, candidate dashboard locks.

Phase 3
Admin Unlock (+1)

Admin clicks Authorize & Unlock on the candidate row to grant exactly +1 fresh assessment token.

Phase 4
Dynamic Re-Lock

The Unlock button disappears immediately and only reappears once the candidate exhausts their newly granted token.

Smart Token Formula: allowed_total = default_allowed + extra_allowed  |  remaining_tokens = max(0, allowed_total - attempts_used)
Automated Email Dispatch

Upon unlocking a candidate's session, the backend automatically triggers an HTML email notification to the candidate informing them that their studio session has been authorized.

Module 03

2-Strike Automated Proctoring Protocol

Standard placement assessments enforce automated tab-switch and focus-loss tracking via browser visibility APIs to ensure academic and recruitment integrity.

Strike 1: Modal Warning

When a candidate navigates away or minimizes the exam tab, a full-screen warning modal locks their screen. The candidate must explicitly click "I Understand & Resume Assessment" to acknowledge.

Strike 2: Session Termination

A second focus-loss event triggers immediate session termination, recording an official Terminated (Breach) status with 0/10 score and code-of-conduct infraction logs.

Quota Token Protection

To prevent malicious locks, terminated sessions are automatically filtered by real_attempt_filter() so they do NOT burn candidate quota tokens.

Module 04

Platform Configuration Parameters (/admin/settings)

Recruitment administrators can fine-tune every variable of the AI interview engine with zero server restarts required.

Parameter Default Operational Purpose & Impact
min_questions 3 Minimum interview depth before AI model is permitted to conclude conversation with [END_INTERVIEW].
max_questions 8 Hard ceiling on total questions asked. Upon reaching this number, the candidate is automatically directed to evaluation.
pass_score 3.00 / 10 Hiring benchmark cutoff. Scores ≥ pass_score receive Selected (PASS); lower scores receive Rejected (FAIL).
question_timer_seconds 90s Per-question response countdown clock displayed on candidate assessment screen (adjustable from 20s to 180s).
default_difficulty student Adjusts AI question complexity prompt tuning: student (fundamentals), mid-level (system design), senior (architecture).
enable_attempt_limits Enabled Global master toggle. When disabled, attempt quotas are bypassed and all candidates enjoy Unlimited Sessions.
default_allowed_interviews 2 Initial token allotment assigned to every newly registered candidate profile upon account creation.
